# ECG Diagnosis Suite - Frontend

React + TypeScript frontend for ECG diagnosis system.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run frontend tests
npm test -- --run
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Axios
- Vitest

## Project Structure

```
frontend/
├── src/
│   ├── components/   # React components
│   ├── pages/        # Page components
│   ├── api/          # API client
│   ├── utils/        # Utility functions
│   ├── App.tsx       # Root component
│   └── main.tsx      # Entry point
├── public/           # Static assets
└── package.json
```
