## 项目概述

**ECG Diagnosis Suite** 是一个基于深度学习的心电图智能诊断系统。

### 核心功能

- 图片上传和预处理
- AI模型诊断
- 结果可视化
- PDF报告生成

### 技术栈

- **前端**: React + TypeScript + Tailwind CSS
- **后端**: FastAPI + PyTorch
- **数据库**: PostgreSQL
- **部署**: Docker + Nginx
